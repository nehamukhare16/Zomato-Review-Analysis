# 🍽️ Zomato Review Analysis

This is a web application that analyzes Zomato restaurant reviews using Natural Language Processing (NLP).  
The app performs **sentiment analysis** to classify reviews as **positive, negative, or neutral**, and provides useful insights through simple visualizations.

---

## 🚀 Features
- Analyze customer reviews in real-time  
- Sentiment classification (Positive / Negative / Neutral)  
- Word frequency and word cloud visualization  
- Simple and interactive web interface  

---

## 🛠️ Tech Stack
- **Python**  
- **Flask / Streamlit** (for the web app)  
- **Pandas, NumPy**  
- **NLTK / Scikit-learn**  
- **Matplotlib / WordCloud**
